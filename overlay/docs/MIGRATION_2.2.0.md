# KSM 2.2.0 마이그레이션 작업·검증

## 분리 원칙

- 원본 기준: KSM 2.2.0 `63d6546808fe3afad4469f3e4d12ca85145650d8`.
- 기존 2.1.0 개발 폴더·play-test·배포물은 변경하지 않습니다.
- 전체 소스와 patch+overlay 저장소 모두 로컬 `feature/ksm-2.2.0` 브랜치로 분리합니다. 기본 브랜치 병합·원격 푸시·릴리즈 게시를 하지 않았습니다.
- 모드 버전은 0.5.4-beta4를 유지하며, 패키지명·프로그램 제목·설치 계약에서 기반 게임 2.2.0을 명시합니다. 공개 배포 전 버전 정책은 별도로 결정합니다.

## 전용 설치기

`KsmEnhancedVertical_KSM2.2.0_0.5.4-beta4_Setup.exe`는 원본 2.2.0 EXE만 지원합니다. 이미지·UI·언어·사용자 데이터의 원본 해시를 요구하지 않습니다. DLL은 실행하지 않고 PE 형식·필수 export를 확인합니다.

설치 계약은 `ksm-2.2.0-enhanced-skin-v1`입니다. 2.1.0 모드 설치 기록은 복구·변경 전에 차단합니다. 2.1.0용 모드의 자동 업데이트·제거 도구가 아닙니다. 별도 2.2.0 폴더를 사용하는 것이 QA 경로입니다.

최초 파일 백업·트랜잭션 복구·수정 이미지 보존·안전한 빈 폴더 정리는 유지합니다. 점수/EX/코스 기록·설정·악곡·사용자 스킨은 설치 대상에서 제외합니다. 원본 게임 EXE·일반 악곡·SDK를 배포하지 않습니다.

## 무음 검증 방법

실제 장치를 사용하지 않는 검증된 mock ASIO가 PCM을 버립니다. ASIO 초기화 실패 시 실제 WASAPI로 넘어가는 fallback도 테스트에서 금지합니다. 화면 검사는 전환하지 않는 별도 데스크톱과 WARP를 사용하며 전역 입력·포커스 이동·시스템 음량 변경을 하지 않습니다. 진단 오류창도 파일로 기록합니다.

- 원본 테스트 48개를 모두 유지한 73개 유닛 사례, 91,991개 assertion 통과.
- EX 125, APS 142, 판정 설정 1,657, 스킨 3,442개 진단 검사 통과.
- 가로·세로의 실제 메시/UV 기하, 렌더 컨텍스트, 프리뷰-인게임 화면 비교 통과.
- 제공된 복잡한 레이저 채보 2개의 가시 범위·실제 그리기 회귀 통과. WARP 실행 시간은 GPU 성능 비교로 취급하지 않음.
- 언어 5종 옵션의 첫/끝 항목 스크롤·표시와 가로/세로 선곡 로딩·추가 행 배치 검사 통과.
- 일본어·간체·번체·한국어·확장 한자·이모지·결합 문자·긴 경로 183개 검사 통과. 글꼴에 없는 이모지의 컬러 렌더링을 보장하지 않음.
- 최종 일반 Release의 모의 ASIO 11개 시나리오 통과. 정상·동시성·초기화 실패에서 실제 출력으로 fallback하지 않음.

재실행 절차는 `scripts/BuildUnitTests.ps1`, `tests/RunSilent220.py`, `tests/UnicodePathTests.py --silent-host`, `scripts/RunAudioTests.ps1`, `installer/tests/UpdateEngine.py`, `installer/tests/Upstream220.py`입니다. 무음 환경에서는 옛 실행 스크립트를 임의로 사용하지 마세요. `RunSilent220.py`는 진단 빌드와 검증된 mock DLL이 없으면 중단합니다.

## 남은 검증 제한

실제 WASAPI/TOPPING ASIO 출력·물리 입력/음향 지연·하드웨어 GPU 및 OBS 부하 성능은 측정하지 않았습니다. 무음 진단 빌드로 실행 경로를 검사했으며, 일반 Release는 빌드·내장·파일 무결성 검증을 수행합니다. 모든 원본 수정에 독립적인 실제 입력 E2E를 구현한 것은 아닙니다. Linux/macOS 소스는 유지하지만 해당 OS 빌드·실행은 미검증입니다. 정식 배포 준비 완료나 모든 환경 동일성을 의미하지 않습니다.

초기 검사에서 드러난 테스트 환경 문제(합성 기하 자산 누락, 캡처 경로, 수동 mock의 콜백 미진행)는 harness를 수정했습니다. 실제 게임의 통과 기대값을 완화한 것은 아닙니다. 기존 실패 로그는 로컬 research/evidence에 남깁니다.
