# 모드 제거 후 빈 폴더 안전 정리 계획

- 파일 제거·원본 복원이 확정된 뒤에만 폴더를 정리한다. 내용물의 재귀 삭제는 하지 않는다.
- 신규 설치는 선택 필드 createdDirectories에 설치 전 없던 배포 경로의 부모 폴더를 기록한다. 빈 목록은 정리 대상 없음으로 처리한다.
- 기존 설치는 검증된 파일 목록의 mods/enhanced, mods/vertical, skin_preview 영역만 대상으로 하며, 공용 mods 부모는 유지한다.
- 게임 루트, 공용 imgs/lang/shaders/ui, 악곡·스킨·점수·설정·로그·백업·복구 경로는 보호한다.
- 상태/저널의 폴더 목록은 형식·중복·경로·파일 목록과의 관계를 변경 전에 검증한다. 실제 삭제 때 링크·정션·폴더 형식을 다시 검사한다.
- 각 경로의 디렉터리 핸들을 열어 이름 변경을 막고, 핸들 기반 Windows 빈 폴더 삭제 API만 사용한다. 파일이 추가되면 삭제가 거부된다.
- 커밋한 저널에 후보 목록을 남겨 정리 중 중단을 복구한다. 커밋 후 정리 실패로 파일 제거를 되돌리지 않는다.
- 정상 비어 있지 않은 폴더는 보존 사유를 기록한다. 권한·잠금 등 오류는 경고로 남기고 완료 화면과 JSON에 표시한다.
- 새/기존 설치, 보호 경로, 숨김 파일, 사용자 폴더, 정션, 잠금, 동시 파일 추가·이름 변경, 중단·복구와 원본 기록 해시를 검사한다.
- 0.5.1-beta1을 유지하고 내부 리비전으로 구분한다. 기존 ZIP 백업·검증 후 README 3종과 해시/빌드정보/검증 결과를 갱신한다.
