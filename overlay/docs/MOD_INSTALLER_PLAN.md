# KSM Enhanced Vertical 설치기 개발 계획

## 목표와 사용 방식
- Windows x64 네이티브 단일 `KsmEnhancedVerticalSetup.exe`로 설치·검증·제거를 제공한다. PowerShell/Python/.NET을 사용자에게 요구하지 않는다.
- 설치 EXE 옆의 KSM 폴더를 자동 인식하며, 다른 위치에서는 폴더 선택 창을 표시한다. 프로세스 현재 디렉터리에는 의존하지 않는다.
- 경로, 호환성, 설치 버전과 진행 상태 및 폴더 선택/설치/제거를 표시한다. 동일 버전의 중복 설치는 막는다.
- 일본어 기본, EN/JP/KR/SC/TC 선택. 제거도 같은 설치 EXE를 재사용하며 별도 관리 프로그램·시작 메뉴를 만들지 않는다.

## 구현과 패키지
- 공용 C++/Win32 엔진을 GUI와 inspect/install/verify/remove 비대화형 검사에서 함께 사용한다.
- 게임 코드를 변경하지 않고 검증된 일반 Release `20261023-234835-524ce9c3` (SHA256 F5E014B9E6DE87037403A49F1652C9B6DE308A61DE49BEE4B66100882D232F70)를 사용한다.
- 필수 모드 파일만 압축 내장한다. 원본 EXE·일반 악곡·SDK·사용자 데이터를 포함하지 않는다. 피아노 테스트 리소스와 필요한 라이선스는 포함한다.
- KSM 2.1.0 Windows 원본 EXE 및 리소스 계약을 검증한다. 게임 원본 옆에 모드 EXE를 설치한다.
- 동일 파일은 건너뛰고 필요한 공용 리소스는 백업 후 적용한다. 사용자 스킨은 설치 대상에서 제외한다.
- 자동 업데이트는 제공하지 않는다. 다른 버전은 제거 후 재설치한다. 검증 가능한 기존 설치 기록도 제거를 지원한다.

## 제거 정책과 기록 보호
| 종류 | 정책 |
|---|---|
| 설치 뒤 수정·삭제된 이미지 | 현재 상태 유지. 설치 전 백업이 있으면 복구 자료로 남김 |
| 수정하지 않은 이미지 | 설치 전 파일 복원 또는 새 파일 제거 |
| 언어 파일 | 설치 전 상태 복원. 설치 뒤 편집본은 복구 폴더에 보관 |
| 기타 모드 파일 | 기존 파일 복원/새 파일 제거. 수정본은 복구 폴더에 보관 |
| 점수·설정·악곡·사용자 스킨 | 쓰기·삭제·복원 대상에서 제외 |

- 모든 `.ksc`, `score/`, `score_backup/`, `courses/score/`와 EX `_additional.ksc`를 보호한다. 설치 후 추가된 기록도 보존한다.
- 언어 선택, 오프셋, 키 배치, 스킨 설정과 장비 보정 정보를 설치 당시로 되돌리지 않는다.
- 설치 목록의 개별 파일만 처리한다. 게임/사용자 폴더 전체를 삭제하지 않는다. 수정 이미지가 남으면 완료 결과에 표시한다.

## 안전성과 검증
- 변경 전 패키지 해시, 대상 호환성, 공간/쓰기 권한, 실행 중인 게임과 파일 잠금을 검사한다. 프로세스를 강제로 종료하지 않는다.
- 백업·스테이징·작업 저널을 변경 전에 저장한다. 오류/취소 시 롤백하며 강제 종료 뒤 재실행 시 미완료 작업을 복구한다.
- 경로 이탈·링크·조작된 설치 기록·백업 누락을 거부한다. 점수 보호는 설치 기록보다 우선한다.
- 일반 폴더에서는 권한 상승 없이 실행하며, 권한 부족 때만 사용자에게 상승을 요청하고 대상/작업을 재검증한다.
- 격리된 복사본에서 설치→실행→제거→재설치, 9/10/11필드 점수, 설치 후 기록, 코스 기록, 수정 이미지 유지와 언어 복원을 검사한다.
- 한글/일본어/공백 경로, 5개 UI 언어, 잠금·권한·공간·손상·중단 복구와 기존 54개 환경 검사의 관련 동작을 공용 엔진으로 검사한다.

## 전달
- 버전 0.5.1-beta1. 기존 배포물과 구분한 설치기 ZIP에 EXE, KO/EN/JA 안내와 영문 BUILD_INFO를 넣는다.
- 파일 해시 목록·검증 결과·ZIP SHA256은 ZIP 옆에 둔다. 기존 릴리즈를 덮어쓰지 않는다.
- 개발 EXE, play-test, 사용자 기록과 검토 브랜치를 유지한다. 실제 사용자 폴더 설치, Git 푸시, 릴리즈 업로드는 포함하지 않는다.
