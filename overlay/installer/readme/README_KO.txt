KSM Enhanced Vertical Mod 0.5.5-Beta5
지원 게임: K-Shoot Mania 2.2.0 Windows x64

# 지원 버전
이 설치기는 원본 KSM 2.2.0 전용입니다. 2.1.0용 모드를 업데이트하거나 제거하지 않습니다.
2.1.0 환경을 옮기려면 원본을 먼저 백업하고, 해당 버전 설치기로 모드를 제거한 뒤 공식 KSM 2.2.0 업데이트를 적용하세요. 모드 설치 상태에서 원본 EXE만 교체하지 마세요.
설치기 실행에 PowerShell, Python, .NET을 따로 설치할 필요는 없습니다.

# 설치와 업데이트
1. 대상 폴더에서 실행 중인 게임을 종료하세요.
2. KsmEnhancedVertical_0.5.5-Beta5_Setup.exe를 실행하세요.
3. kshootmania.exe가 있는 KSM 2.2.0 폴더를 선택하세요. 설치기를 해당 폴더에 두면 자동으로 인식합니다.
4. [모드 설치]를 누르세요. 지원하는 기존 2.2.0 모드가 있으면 [모드 업데이트]가 활성화됩니다.
5. 완료 후 같은 폴더의 ksm-enhanced-vertical.exe를 실행하세요. 원본 kshootmania.exe도 계속 사용할 수 있습니다.

설치기 언어는 일본어가 기본이며 EN / JP / KR / SC / TC를 선택할 수 있습니다. 기존 게임 언어·키 배치·오프셋은 유지합니다.
실행 시 새 설치기를 확인하며 [업데이트 확인]으로 다시 확인할 수 있습니다. 호환 릴리즈가 있으면 [릴리즈 페이지 열기]로 이동하세요. 자동 다운로드·설치는 하지 않으며 인터넷 연결이 없어도 로컬 설치·제거는 가능합니다.

# 제거와 보존
같은 설치기를 보관하고, 제거할 때 대상 폴더를 선택해 [모드 제거]를 누르세요. 별도 제거 프로그램은 설치하지 않습니다. 설치 기록이 없는 수동 설치는 자동 제거할 수 없습니다.
일반·EX·코스 기록, 새로 달성한 기록, 점수 백업, 설정, 악곡, 사용자 스킨은 보존합니다. 직접 수정하거나 삭제한 이미지는 그 상태로 유지합니다.
수정하지 않은 모드 파일은 제거하거나 최초 설치 전 파일로 복원합니다. 수정된 언어·기타 관리 파일은 .ksm-enhanced-recovery/<작업번호>/에 보관합니다.
설치기가 만든 빈 모드 폴더는 안전하게 정리하지만 skins/와 사용자 파일·백업·복구 폴더는 남깁니다.
.ksm-enhanced-install.json과 .ksm-enhanced-backup/은 편집·삭제하지 마세요. 중단됐다면 같은 설치기로 같은 폴더를 선택해 복구하세요.

# 모드 기능
- 가로·세로 플레이와 세로 화면용 UI
- 뷰포트 커스텀과 사용자 스킨
- P-CRITICAL, EX 스코어와 추가 기록·리절트 표시
- HARD+APS 및 EFF.RATE 선택 보존 옵션
- 판정 타이밍 설정과 ASIO 출력·장치별 추가 판정 보정
- 레이저·직각 레이저·노트 두께, 키빔 길이·투명도 조절

# 스킨 사용
설치·업데이트 시 게임 폴더에 skins/가 없으면 생성합니다. 스킨마다 그 안에 별도 폴더를 만드세요.
예: [게임폴더]/skins/MySkin/button.png
이미지는 imgs/의 상대 경로와 파일명을 맞춰 넣으세요. 모든 이미지를 교체할 필요는 없으며 없는 이미지는 imgs/의 기본 이미지로 대체됩니다.
게임의 Viewport Custom에서 스킨을 선택하세요. Yellow 누락 이미지 설정으로 교체하지 않은 이미지를 확인할 수 있습니다. 모드 이미지도 imgs/에 포함되어 있습니다.
