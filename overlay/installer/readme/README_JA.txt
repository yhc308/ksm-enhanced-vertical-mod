KSM Enhanced Vertical Mod 0.5.1-beta1 インストールガイド
対応バージョン: K-Shoot Mania 2.1.0 Windows x64

# インストール
1. kshootmania.exe が起動中の場合は終了してください。
2. KsmEnhancedVerticalSetup.exe を起動してください。
3. kshootmania.exe があるフォルダーを選び、［モードをインストール］を押してください。（インストーラーの EXE を KSM フォルダーに置くと、その場所を自動選択します。）
4. インストール後、同じフォルダーの ksm-enhanced-vertical.exe からモードを起動します。
5. 原版の kshootmania.exe は保持されます。

# 削除と再インストール
* このインストーラーの EXE を使わずに手動導入したものは、インストーラーでは削除できません。
1. 同じインストーラーの EXE を再び起動し、KSM フォルダーを選んで［モードを削除］を押してください。
2. 別のアンインストーラーやスタートメニュー項目は作成しないため、この EXE を保管してください。
3. 別のモードバージョンに切り替える場合は、先に現在のバージョンを削除してから再インストールしてください。

# モード削除時の注意事項

インストール記録（.ksm-enhanced-install.json）とバックアップを編集しないでください。復元できなくなる場合があります。
編集した言語ファイルやその他のモードファイル（モードが追加した画像など）は、.ksm-enhanced-recovery/<処理ID>/ にバックアップを残します。
バックアップと復元資料は安全のため保持します。インストーラーの使用中に削除しないでください。

通常・EX・コース記録、導入後に達成した記録、スコアのバックアップ、設定、曲、ユーザースキンは保持します。
自分で編集・削除した画像は、その状態を維持します。

変更していない導入画像は原版に復元し、モードが追加したファイルのみ削除します。

# エラーと案内
ゲームが終了しているか、フォルダーが正しいか、空き容量が十分かを確認してください。処理が中断された場合は、同じ EXE で同じフォルダーを選択して復旧します。
バックアップの破損や未対応の原版では、上書きせずに停止します。書き込み権限が足りない場合は管理者権限を要求します。
テスト用の未署名インストーラーです。自動更新は提供しません。

# モードの追加コンテンツ
- 縦画面プレイ
- ビューポートのカスタマイズ、スキン機能の追加（追加される skins フォルダーを使用）
- EX スコアとリザルト画面の改善
- HARD+APS
- 判定設定モード

# スキンについて
- モード用の画像も imgs に追加されます。
- 対応する画像と同じファイル名のスキン画像を skins フォルダー内に追加すると適用できます。

問題を GitHub に報告する際は、ビルドID・Windows のバージョン・原版 KSM のバージョン・再現手順・エラー内容をお知らせください。

エラーログ: [ゲームフォルダー]\log\session-<番号>-pid<PID>\events-0.log
GUI の最終処理結果: %TEMP%/KsmEnhancedVerticalSetup-last-result.json
ライセンス: [ゲームフォルダー]\mods\enhanced\ および [ゲームフォルダー]\mods\enhanced\licenses\

# 削除後の空フォルダー整理
モードファイルの削除が正常に完了した後、今回の導入で新規作成したと記録されたフォルダーだけを、空の場合に限り深い階層から整理します。
作成記録のない旧インストールでは、管理対象として確認できる mods/enhanced、mods/vertical、skin_preview 内だけを整理し、共通の親フォルダー mods は残します。
ファイル（隠しファイルを含む）や別のフォルダーが残っていれば削除しません。内容を再帰的に一括削除することはありません。
導入前からある共通フォルダー、曲、ユーザースキン、記録、設定、ログ、導入時のバックアップと復元資料は保持します。
権限やロックで整理できない場合はフォルダーを残し、完了画面と最終処理結果の JSON に警告を表示します。
整理中に中断した場合は、同じインストーラーで同じフォルダーを選択し、残りの整理を復旧してください。
