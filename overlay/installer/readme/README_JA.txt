KSM Enhanced Vertical Mod 0.5.5-Beta5
対応ゲーム: K-Shoot Mania 2.2.0 Windows x64

# 対応バージョン
このインストーラーは原版KSM 2.2.0専用です。2.1.0用Modの更新・削除には対応しません。
2.1.0から移行する場合は、まず原版をバックアップし、そのバージョンのインストーラーでModを削除してから公式KSM 2.2.0アップデートを適用してください。Modのインストール中に原版EXEだけを置き換えないでください。
実行のためにPowerShell、Python、.NETを別途インストールする必要はありません。

# インストール・更新
1. 対象フォルダーで実行中のゲームを終了します。
2. KsmEnhancedVertical_0.5.5-Beta5_Setup.exeを実行します。
3. kshootmania.exeがあるKSM 2.2.0フォルダーを選択します。インストーラーをそのフォルダーに置くと自動認識します。
4. 「モードをインストール」を選択します。対応する2.2.0用Modがある場合は「モードを更新」が有効になります。
5. 完了後、同じフォルダーのksm-enhanced-vertical.exeを起動します。原版kshootmania.exeも引き続き使用できます。

インストーラーの既定言語は日本語で、EN / JP / KR / SC / TCを選択できます。ゲームの言語・キー設定・オフセットは保持します。
起動時に新しいインストーラーを確認します。「更新を確認」で再確認し、対応する更新があれば「リリースページを開く」から入手してください。自動ダウンロード・インストールは行いません。インターネットに接続していなくてもインストール・削除できます。

# 削除・保持するデータ
このインストーラーを保管し、削除時は同じゲームフォルダーを選んで「モードを削除」を押してください。別のアンインストーラーは追加しません。インストール記録がない手動導入版は自動削除できません。
通常・EX・コース記録、新しく達成した記録、スコアバックアップ、設定、楽曲、ユーザースキンは保持します。編集・削除した画像もその状態を維持します。
未変更のModファイルは削除するか、初回インストール前のファイルに戻します。編集した言語ファイルなどは.ksm-enhanced-recovery/<作業番号>/に保管します。
インストーラーが作成した空のModフォルダーは安全に整理します。skins/、ユーザーファイル、バックアップ・復旧用フォルダーは残します。
.ksm-enhanced-install.jsonと.ksm-enhanced-backup/を編集・削除しないでください。中断した場合は同じインストーラーで同じフォルダーを選択して復旧します。

# Modの機能
- 横画面・縦画面プレイと縦画面向けUI
- ビューポートのカスタマイズとユーザースキン
- P-CRITICAL、EXスコア、追加記録・リザルト表示
- HARD+APSと選択したEFF.RATEの保持設定
- 判定タイミング設定、ASIO出力とデバイス別の追加判定補正
- レーザー・直角レーザー・ノーツの太さ、キービームの長さ・不透明度設定

# スキンの使い方
インストール・更新時にゲームフォルダーのskins/がなければ作成します。スキンごとにその中へフォルダーを追加してください。
例: <ゲームフォルダー>/skins/MySkin/button.png
imgs/と同じ相対パス・ファイル名で画像を配置します。すべて置き換える必要はなく、不足する画像はimgs/の標準画像で補完します。
Viewport Customでスキンを選択してください。Yellowの欠落画像設定で未置換の画像を確認できます。Modの画像もimgs/に含まれています。
